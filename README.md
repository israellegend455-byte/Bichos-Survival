BICHOS SURVIVOR

Bichos Survivor es un videojuego de supervivencia por oleadas (bullet heaven / roguelite) desarrollado de forma independiente para navegadores web. Inspirado en mecánicas de títulos del género, el juego destaca por ofrecer una experiencia original con modelos, balanceos y mecánicas de desarrollo propio, completamente libre de microtransacciones.
El objetivo consiste en seleccionar a un bicho compañero, sobrevivir a masivas hordas de enemigos en tiempo real, recolectar experiencia para subir de nivel y desbloquear poderosos ataques automáticos para dominar el mapa.

Características Principales

• Máxima Accesibilidad: Totalmente optimizado para correr a 60 FPS estables sin lag directo en el navegador. Es compatible con controles de Xbox, PlayStation, teclado (WASD) y pantallas táctiles para dispositivos móviles.

• Modo Cooperativo (COOP): Sistema multijugador en línea integrado mediante códigos de sala de 4 letras para sobrevivir en equipo junto a tus amigos.

• Sistema de Progreso Justo: Incluye un Pase de Batalla gratuito de 30 niveles con recompensas exclusivas, un sistema Gacha para invocar nuevos bichos y un apartado de mejoras permanentes utilizando las monedas conseguidas en el juego.

• Coleccionismo y Desafío: Cuenta con más de 67 bichos únicos divididos en una tabla de clasificación (Tier List) competitiva, variantes Shiny (Brillantes) ultra raras y un Ranking global en tiempo real para registrar los mejores tiempos de supervivencia.
